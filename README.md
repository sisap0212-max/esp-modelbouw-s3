# esp-modelbouw-s3

Bestanden voor automatische software-updates van het mini-billboard (ESP32-S3, 1,8"-scherm, wifi).

**Huidige versie: 2.7**

| Bestand | Wat |
|---|---|
| `billboard_s3.bin` | De nieuwste software. Het bordje haalt die hier zelf op. |
| `herstel_s3.bin` | Vaste versie om op terug te vallen (herstelmodus). |
| `billboard_s3_eerste_installatie.bin` | Volledig bestand voor de allereerste keer flashen (4 MB). |

Niet hernoemen, verplaatsen of verwijderen.
